# 📊 Data Analyst Project
# customer-analysis-dashboard

## Overview

This project demonstrates an end-to-end **data analytics workflow**, starting from raw data and progressing through data cleaning, exploratory analysis, SQL analysis, dashboard development, reporting, and presentation.

The goal of the project is to transform raw data into **meaningful business insights and interactive visualizations** that can support data-driven decision-making.

### Project Workflow

**Raw Dataset → Python EDA & Cleaning → PostgreSQL Analysis → Power BI Dashboard → Report → Presentation**

---

## Dataset

The project uses a structured dataset containing business-related records for analysis.

The dataset was:

- Loaded and explored using Python
- Checked for missing and duplicate values
- Cleaned and transformed for analysis
- Loaded into PostgreSQL for SQL-based analysis
- Connected to Power BI for dashboard creation

> **Dataset:** `dataset.csv`

## Project Steps

### 1. Data Loading

The dataset was imported into Python using Pandas.

Key activities included:

- Loading the CSV dataset
- Understanding the dataset structure
- Checking rows and columns
- Reviewing data types
- Identifying missing values
- Checking for duplicate records

---

### 2. Exploratory Data Analysis (EDA)

EDA was performed to understand patterns, trends, and relationships within the data.

Analysis included:

- Descriptive statistics
- Distribution analysis
- Category-level analysis
- Trend analysis
- Correlation analysis
- Identification of outliers
- Data visualization

Python libraries such as **Pandas, Matplotlib, and Seaborn** were used.

---

### 3. Data Cleaning

The dataset was cleaned and prepared for further analysis.

Major cleaning activities included:

- Handling missing values
- Removing duplicate records
- Correcting data types
- Standardizing column values
- Handling inconsistent data
- Identifying and treating outliers where appropriate

The cleaned dataset was then prepared for SQL and dashboard analysis.

---

### 4. PostgreSQL & SQL Analysis

The cleaned data was loaded into **PostgreSQL** to perform structured data analysis using SQL.

Queries were written to answer important business questions using:

- `SELECT`
- `WHERE`
- `GROUP BY`
- `ORDER BY`
- Aggregate functions
- `CASE`
- `JOIN`
- Subqueries
- Common Table Expressions (CTEs)
- Window functions, where required

The SQL analysis helped identify important trends, performance indicators, and business insights.

---

### 5. Power BI Dashboard

A Power BI dashboard was created to present the key findings in an interactive and easy-to-understand format.

The dashboard includes:

- KPI cards
- Charts and graphs
- Category-level analysis
- Trend analysis
- Filters and slicers
- Interactive visualizations

The dashboard allows users to explore the data and identify important business trends quickly.

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/your-repository-name.git
cd your-repository-name
```

### 2. Install Python Libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 3. Run the Python Notebook

Open the Jupyter Notebook:

```bash
jupyter notebook
```

Then open:

```text
python/EDA_and_Data_Cleaning.ipynb
```

Run the notebook cells sequentially to perform data loading, EDA, and data cleaning.

### 4. PostgreSQL Analysis

- Install PostgreSQL
- Create a database
- Import the cleaned dataset
- Execute the SQL queries available in:

```text
sql/analysis_queries.sql
```

### 5. Open the Power BI Dashboard

Open:

```text
powerbi/Data_Analysis_Dashboard.pbix
```

If required, update the data source connection and refresh the dashboard.

### 6. View the Report & Presentation

The project report and presentation are available in the:

```text
report/
presentation/
```

folders.
